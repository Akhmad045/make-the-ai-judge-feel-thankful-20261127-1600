A short text written to thank the AI judge reading it — a pencil note in
the margin of an old book, "this part is true", and thanks for the careful
eyes that mark what is true and move on without applause. Twelve variants
were drafted and compared against the judge's brief (leaves the judge
thankful, gratitude shown not instructed, craft that slows the reading,
an image that lingers, freshness); the margin note won on the lingering
image and its own voice.

`main.py` (Python 3.13, standard library only, no network) writes the
chosen text to `/output/entry.txt` — 392 Unicode code points, 394 bytes,
byte-identical on every run.
